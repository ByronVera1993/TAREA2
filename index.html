MÓDULO 01 — SISTEMA

La máquina, por dentro

Comprender la arquitectura permite leer las huellas que deja un sistema cuando está en funcionamiento.

01

La arquitectura de computadores estudia la forma en que los componentes de un sistema se organizan para recibir, procesar, almacenar y comunicar información. Es el punto de partida para interpretar eventos técnicos con precisión.

MÓDULO 02 — CONECTIVIDAD

El dato nunca viaja solo

Una red es un sistema de dispositivos, medios y reglas que hace posible el intercambio de información.

01

Dispositivos

Equipos finales, switches, routers y puntos de acceso que originan o dirigen la comunicación.

02

Medios

Cables, fibra óptica y señales inalámbricas que transportan los datos.

03

Protocolos

Reglas como TCP/IP que permiten que los sistemas se entiendan.

04

Direcciones

Identificadores que ubican interfaces y dispositivos dentro de la red.

LABORATORIO 02.1

IP vs. MAC

Dos identificadores, dos niveles de lectura. La IP es lógica y puede variar según la red. La MAC está vinculada a la interfaz física.

IP / lógica192.168.1.10Identifica una ubicación en la red
MAC / física00:1A:2B:3C:4D:5EIdentifica una interfaz de red

MÓDULO 03 — FORENSE DIGITAL

Leer lo que el sistema deja atrás

La investigación técnica conecta componentes, comunicaciones y evidencia para construir una explicación verificable.

A

Memoria RAM

La RAM contiene evidencia volátil: información temporal que puede desaparecer al apagar el equipo.

  • Procesos activos
  • Conexiones de red
  • Datos presentes en memoria
B

Registros del sistema

Los registros y el contexto de ejecución ayudan a reconstruir qué ocurrió, cuándo ocurrió y cómo respondió el sistema.

  • Secuencia de eventos
  • Estado de ejecución
  • Correlación temporal
C

Tráfico de red

Observar las comunicaciones permite reconocer participantes, protocolos y patrones potencialmente sospechosos.

  • Direcciones involucradas
  • Protocolos utilizados
  • Patrones de comunicación

Conclusiones

Una mirada integrada sobre lo aprendido y su utilidad profesional.
